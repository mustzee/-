## 💻 실행 방법

각 예제를 실행하려면:
```bash
go run 01-hello-world.go
go run 02-variables.go
# ... 등등
```

또는 모든 파일을 한 번에 테스트:
```bash
for f in *.go; do echo "=== $f ==="; go run "$f"; done
```
