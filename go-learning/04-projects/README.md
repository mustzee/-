# 04. 실전 프로젝트

배운 내용을 활용한 실전 프로젝트입니다.

## 📋 프로젝트 목록

### 1. [CLI TODO 앱](01-todo-cli/)
명령줄 기반 할 일 관리 앱

**학습 내용:**
- 파일 입출력
- JSON 처리
- 슬라이스 조작

**실행:**
```bash
cd 01-todo-cli
go run main.go
```

### 2. [간단한 웹 서버](02-simple-web-server/)
HTTP 웹 서버

**학습 내용:**
- net/http 패키지
- 라우팅
- JSON API

**실행:**
```bash
cd 02-simple-web-server
go run main.go
```

### 3. [동시성 패턴](03-concurrency-patterns/)
실용적인 동시성 예제

**학습 내용:**
- Goroutine
- Channel
- Worker Pool

**실행:**
```bash
cd 03-concurrency-patterns
go run main.go
```
