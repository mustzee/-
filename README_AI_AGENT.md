## 개요

이 AI 도우미는 일상생활에서 **논리적인 결정**을 내리는데 도움을 주는 대화형 에이전트입니다.

### 특징
- ✅ **100% 무료** - 설치나 회원가입 불필요
- ✅ **브라우저에서 실행** - 단일 HTML 파일
- ✅ **개인정보 안전** - 모든 데이터는 로컬에만 저장
- ✅ **초보자 친화적** - 간단한 대화형 인터페이스
- ✅ **교육용으로 완벽** - AI 작동 원리를 배울 수 있음

## 주요 기능

### 1. 📊 할 일 우선순위 분석
**아이젠하워 매트릭스** 기반으로 할 일을 분류합니다.

```
긴급 + 중요     |  중요하지만 긴급하지 않음
----------------|-------------------------
지금 바로!      |  계획해서 처리
----------------|-------------------------
긴급만          |  긴급하지도 중요하지도 않음
빠르게 처리     |  제거/최소화
```

**예시 질문:**
- "오늘 할 일이 너무 많아"
- "무엇부터 해야 할지 모르겠어"

---

### 2. 🤔 의사결정 도우미
중요한 결정을 내릴 때 **논리적 프로세스**를 제공합니다.

**5단계 의사결정:**
1. 선택지 나열
2. 평가 기준 설정
3. 장단점 분석
4. 점수화
5. 직관 확인

**예시 질문:**
- "중요한 결정을 해야 해"
- "두 가지 중에 고민이야"

---

### 3. ⏰ 시간 관리 조언
효율적인 시간 활용을 위한 전략을 제시합니다.

**포함 내용:**
- 📅 일일 계획 세우기
- 🍅 포모도로 테크닉 (25분 집중 + 5분 휴식)
- ⚡ 시간 도둑 제거법
- 🎯 80/20 법칙 적용

**예시 질문:**
- "시간 관리가 어려워"
- "집중이 안 돼"

---

### 4. 💪 건강 습관 추천
건강한 생활을 위한 과학적 조언을 제공합니다.

**카테고리:**
- 🥗 식습관 (물, 채소, 가공식품 줄이기)
- 🏃 운동 (주 3회, 30분, 작게 시작)
- 😴 수면 (7-8시간, 규칙적 시간)
- 🧘 정신 건강 (명상, 감사 일기)

**예시 질문:**
- "건강하게 살고 싶어"
- "수면 개선 방법 알려줘"

## 사용 예시

### 예시 1: 할 일 우선순위
```
사용자: "오늘 할 일이 너무 많아요"

AI: 할 일을 아이젠하워 매트릭스로 분류해보세요:
     - 긴급 + 중요 → 즉시 처리
     - 중요만 → 일정 계획
     - 긴급만 → 빠르게 또는 위임
     - 둘 다 아님 → 제거
```

### 예시 2: 의사결정
```
사용자: "새 노트북을 살지 말지 고민이에요"

AI: 5단계 의사결정 프로세스를 따라가세요:
    1. 선택지: 구매 / 구매 안 함 / 중고 구매
    2. 기준: 예산, 필요성, 성능, 긴급성
    3. 각 선택지의 장단점 나열
    4. 기준별로 점수 매기기
    5. 결과가 직관과 맞는지 확인
```

## AI 작동 원리

### 🧠 규칙 기반 시스템 (Rule-Based System)

이 AI는 **규칙 기반 추론 엔진**을 사용합니다:

```javascript
// 간단한 예시
if (사용자 입력에 "할 일"이 포함) {
    → 우선순위 조언 제공
} else if (사용자 입력에 "결정"이 포함) {
    → 의사결정 프로세스 제공
}
```

### 핵심 컴포넌트

#### 1. **패턴 매칭**
사용자 입력에서 키워드를 찾습니다.
```javascript
patterns: ['할 일', '해야', '많아', '바빠', '우선순위']
```

#### 2. **규칙 엔진**
매칭된 패턴에 따라 적절한 조언을 선택합니다.
```javascript
if (키워드 매칭) {
    return 관련 조언()
}
```

#### 3. **컨텍스트 관리**
사용자와의 대화 내용을 기억합니다.
```javascript
userContext: {
    recentTopics: [],
    preferences: {}
}
```

#### 4. **통계 추적**
사용자의 사용 패턴을 로컬 저장소에 저장합니다.
```javascript
localStorage.setItem('aiAgentStats', JSON.stringify(stats));
```

## 초보자를 위한 설명

### Q1: 이게 "진짜" AI인가요?
**A:** 이것은 **규칙 기반 AI**입니다. ChatGPT 같은 **학습형 AI**와는 다르지만, 여전히 유용한 AI의 한 형태입니다.

| 규칙 기반 AI | 학습형 AI (ML/DL) |
|-------------|-------------------|
| 사람이 규칙 작성 | 데이터로 학습 |
| 예측 가능 | 창의적 |
| 빠름 | 느릴 수 있음 |
| 투명함 | 블랙박스 |
| 무료 | 비용 발생 가능 |

**언제 사용?**
- 규칙 기반: 논리적 추론, 진단, 분류
- 학습형: 패턴 인식, 예측, 창작

---

### Q2: 내 데이터는 안전한가요?
**A:** 100% 안전합니다!

- ✅ 모든 데이터는 **브라우저 로컬 저장소**에만 저장
- ✅ 인터넷 연결 불필요 (오프라인 작동)

- ✅ 개인정보 수집 **전혀 없음**

```
ai-agent.html
├── HTML Structure
│   ├── 채팅 인터페이스
│   ├── 기능 버튼
│   ├── 우선순위 매트릭스
│   └── 통계 대시보드
│
├── CSS Styling
│   ├── 그라디언트 배경
│   ├── 반응형 그리드
│   ├── 애니메이션
│   └── 모바일 최적화
│
└── JavaScript Logic
    ├── LogicalAgent 클래스
    │   ├── processInput() - 메인 추론 엔진
    │   ├── priorityAdvice() - 우선순위 조언
    │   ├── decisionAdvice() - 의사결정 도움
    │   ├── timeManagement() - 시간 관리
    │   └── healthAdvice() - 건강 조언
    │
    └── UI 컨트롤러
        ├── sendMessage() - 메시지 전송
        ├── addMessage() - 메시지 표시
        └── 기능 버튼 핸들러
```

## 문제 해결

### 메시지가 표시되지 않아요
- 브라우저 콘솔(F12) 확인
- JavaScript 에러 확인
- 최신 브라우저 사용 (Chrome, Firefox, Safari)

### 통계가 사라졌어요
- LocalStorage가 삭제되었을 수 있음
- 브라우저 시크릿 모드에서는 저장 안 됨
- 쿠키/캐시 삭제 시 통계도 삭제됨

### 반응이 느려요
- 브라우저 캐시 삭제
- 다른 탭 닫기
- 페이지 새로고침 (F5)
