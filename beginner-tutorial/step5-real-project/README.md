## 📁 프로젝트 옵션

### 프로젝트 1: 대용량 로그 분석기 📊

**난이도**: ⭐⭐⭐

**기능:**
- 여러 GB의 로그 파일 읽기
- 에러 패턴 찾기
- 시간대별 통계
- 결과 시각화

**사용 기술:**
- Dask (분산 처리)
- Pandas (분석)
- Matplotlib (시각화)

**시작:**
```bash
cd project1_log_analyzer
python main.py --input logs/*.log --output report.html
```

---

### 프로젝트 2: 이미지 배치 프로세서 🖼️

**난이도**: ⭐⭐⭐⭐

**기능:**
- 수천 장의 이미지 병렬 처리
- 크기 조절, 필터 적용
- 진행률 표시
- 결과 저장

**사용 기술:**
- Multiprocessing
- PIL/Pillow
- 진행률 바

**시작:**
```bash
cd project2_image_processor
python processor.py --input images/ --output processed/ --workers 8
```

### 프로젝트 3: 데이터 파이프라인 🔄

**난이도**: ⭐⭐⭐⭐⭐

**기능:**
- CSV 데이터 수집
- 정제 및 변환
- 병렬 처리
- 데이터베이스 저장

**사용 기술:**
- Dask (분산)
- SQLite
- 데이터 검증

**시작:**
```bash
cd project3_pipeline
python pipeline.py --config config.yml
```

```bash
python analyze.py
```

**출력:**
```
로그 파일 읽기... (Dask 사용)

  - 총 크기: 1.2 GB

분석 중...

  ✓ 시간대별 집계
  ✓ IP 통계

결과:
  - 총 에러: 15,432
  - 가장 많은 에러: "Connection timeout" (3,421회)
```
