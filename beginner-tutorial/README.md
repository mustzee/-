# 🎓 완전 초보자를 위한 병렬처리 & 분산처리 학습 가이드

## 👋 환영합니다!

이 튜토리얼은 프로그래밍을 조금 해본 사람이라면 누구나 따라할 수 있도록 만들어졌습니다.
각 단계는 약 30분~1시간 정도 소요되며, 실제로 코드를 실행하면서 배울 수 있습니다.

- ✅ 병렬처리가 무엇이고 왜 필요한지 이해합니다
- ✅ Python으로 간단한 병렬 프로그램을 작성할 수 있습니다
- ✅ 대용량 데이터를 분산 처리할 수 있습니다
- ✅ Rust로 고성능 병렬 프로그램을 맛볼 수 있습니다
- ✅ 실전 프로젝트를 완성할 수 있습니다
