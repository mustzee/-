# 📊 광고 컬렉션 매니저 (Ad Collection Manager)

여러 형태의 광고를 쉽고 효율적으로 수집하고 정리할 수 있는 웹 기반 도구입니다.

## ✨ 주요 기능

### 1. 다양한 광고 형태 지원
- **이미지 광고**: JPG, PNG, GIF 등 모든 이미지 형식
- **영상 광고**: YouTube, Vimeo URL 지원 (자동 썸네일 생성)
- **배너 광고**: 스크린샷 직접 업로드
- **소셜 미디어 광고**: Facebook, Instagram, TikTok 등

### 2. 편리한 수집 방법
- 🖱️ **드래그 앤 드롭**: 이미지를 끌어다 놓기만 하면 됩니다
- 📋 **붙여넣기**: Ctrl+V로 클립보드의 이미지 바로 추가
- 📁 **파일 선택**: 일반적인 파일 선택 대화상자
- 🔗 **URL 입력**: YouTube 등 영상 URL 입력

### 3. 체계적인 정리 시스템
- **카테고리 분류**
  - 소셜 미디어
  - 배너
  - 영상
  - 디스플레이

- **플랫폼별 구분**
  - Facebook, Instagram, YouTube
  - Google Ads, TikTok, Twitter
  - LinkedIn 등

- **태그 시스템**: 자유로운 태그 추가로 세밀한 분류
- **즐겨찾기**: 중요한 광고를 별표로 표시
- **메모 기능**: 각 광고에 설명 추가

### 4. 강력한 검색 및 필터
- 🔍 **통합 검색**: 제목, 설명, 태그에서 검색
- 🎯 **카테고리 필터**: 광고 유형별로 필터링
- 📱 **플랫폼 필터**: 특정 플랫폼의 광고만 보기
- 📅 **정렬 옵션**: 최신순, 오래된순, 제목순

### 5. 데이터 관리
- 💾 **자동 저장**: 브라우저 로컬 스토리지에 자동 저장
- 📤 **데이터 내보내기**: JSON 형식으로 백업
- 📥 **데이터 가져오기**: 이전 백업 복원
- 📊 **실시간 통계**: 전체/이미지/영상/즐겨찾기 개수

### 6. 다양한 뷰 옵션
- ▦ **그리드 뷰**: 카드 형식으로 한눈에 보기
- ☰ **리스트 뷰**: 상세 정보와 함께 목록으로 보기

## 🚀 사용 방법

### 1. 시작하기
```bash
# 파일을 웹 브라우저로 열기
open ad-collection-manager.html

# 또는 브라우저에서 직접 파일 열기
# Chrome, Firefox, Safari, Edge 모두 지원
```

### 2. 광고 추가하기

#### 방법 1: 버튼으로 추가
1. **"➕ 새 광고 추가"** 버튼 클릭
2. 광고 유형 선택 (이미지/영상)
3. 정보 입력:
   - 제목 (필수)
   - 카테고리 (필수)
   - 플랫폼
   - 설명
   - URL (선택)
   - 태그 (엔터로 추가)
4. **"💾 저장"** 클릭

#### 방법 2: 드래그 앤 드롭
1. 이미지 파일을 점선 영역으로 드래그
2. 정보 입력 후 저장

#### 방법 3: 붙여넣기
1. 이미지를 클립보드에 복사
2. 광고 추가 화면에서 **Ctrl+V** (또는 Cmd+V)
3. 정보 입력 후 저장

### 3. 광고 관리하기

#### 검색 및 필터
- **검색창**: 제목, 설명, 태그에서 검색
- **카테고리 필터**: 특정 유형만 보기
- **플랫폼 필터**: 특정 플랫폼만 보기
- **정렬**: 최신순, 오래된순, 제목순

#### 광고 수정/삭제
- **✏️ 수정**: 정보 변경
- **🗑️ 삭제**: 광고 제거 (확인 필요)
- **🔗 보기**: 원본 URL로 이동
- **☆/★**: 즐겨찾기 토글

### 4. 데이터 백업

#### 내보내기
1. **"💾 데이터 내보내기"** 클릭
2. JSON 파일로 저장됨
3. 파일명: `ad-collection-YYYY-MM-DD.json`

#### 가져오기
1. **"📂 데이터 가져오기"** 클릭
2. 이전에 내보낸 JSON 파일 선택
3. 데이터 복원 완료

- 즉각적인 검색 및 필터링
- 부드러운 애니메이션

- **HTML5**: 시맨틱 마크업
- **CSS3**: 현대적인 디자인, 그라디언트, 애니메이션

## 📝 팁과 트릭

### 효율적인 사용법
1. **정기적인 백업**: 주기적으로 데이터 내보내기
2. **일관된 태그**: 동일한 태그명 사용으로 검색 효율 증대
3. **카테고리 활용**: 초기부터 정확한 카테고리 분류
4. **설명 작성**: 나중에 찾기 쉽도록 상세한 설명 추가

### YouTube 썸네일
- YouTube URL 입력 시 자동으로 고품질 썸네일 생성
- 지원 URL 형식:
  - `https://www.youtube.com/watch?v=VIDEO_ID`
  - `https://youtu.be/VIDEO_ID`

### 대량 추가
1. 스크린샷 도구로 광고 캡처
2. 클립보드에 자동 복사됨
3. 광고 추가 화면에서 Ctrl+V
4. 반복

## 🛠️ 문제 해결

### 이미지가 표시되지 않아요
- 브라우저의 로컬 스토리지 용량 확인
- 너무 큰 이미지는 압축 후 업로드 권장 (5MB 이하)

### 데이터가 사라졌어요
- 브라우저 캐시 삭제 시 데이터 손실 가능
- 정기적인 백업 권장 (내보내기 기능 사용)

### 파일을 찾을 수 없어요
- 파일명: `ad-collection-manager.html`
- 더블클릭하거나 브라우저로 드래그
